Ĝi

A private AI assistant that runs on your own computer.

Ĝi (Esperanto for “it”) answers your questions with a language model on your machine. No cloud, no account, no telemetry.

Install ĜiRead the docs
  • Local and privateTalks only to the model server you choose (Ollama or LM Studio), on this computer by default.
  • Installs with aptA signed package for Ubuntu, Linux Mint, Debian and Ubuntu on WSL. Updates arrive with your normal updates.
  • Checks itselfgi selfcheck reports your security baseline; answers from the model are always treated as untrusted.

Quick start

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://gi-ai.app/apt/gi-ai.asc | sudo gpg --dearmor -o /etc/apt/keyrings/gi-ai.gpg
gpg --show-keys /etc/apt/keyrings/gi-ai.gpg      # compare the fingerprint below
echo "deb [signed-by=/etc/apt/keyrings/gi-ai.gpg] https://gi-ai.app/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/gi-ai.list
sudo apt update && sudo apt install gi-ai

Then connect a model server and ask your first question: see Install.

What you need

Ubuntu 24.04 or newer, Linux Mint 22, Debian 12 or newer, or Ubuntu on WSL (Python 3.11+, installed by apt), and a local model server: Ollama on the same machine, or LM Studio (for example on the Windows host of WSL).

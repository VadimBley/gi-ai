Using Ĝi

The full reference is in the manual: man gi.

Commands

CommandWhat it does
gi healthChecks Ĝi and the model server. Exit 0 when the server answers correctly.
gi ask "…"Asks the model a question. --verbose adds speed statistics.
gi init-workspaceCreates your private workspace (folder mode 0700) with a tamper-evident log.
gi task new --type req|bug|vuln --title "…"Creates a private task record; gi task list lists them.
gi selfcheckChecks your security baseline: private workspace, intact log, safe config, private model address.

Add --json for machine-readable output.

Settings

System defaults are in /etc/gi-ai/gi.toml; your own settings go in ~/.config/gi-ai/gi.toml.

Key ([llm])Meaning
backendollama (default), lmstudio, or echo (offline test)
endpointhttp://host:port; @gateway means the Windows host seen from WSL
modelThe model name or id your server offers
allow_remoteMust be true for any address that is not on this computer. Cloud metadata addresses (169.254.169.254, 169.254.170.2, fd00:ec2::254) are always refused
timeout_sSeconds to wait for an answer (1–3600)
reasoningLM Studio only: off (default), low, medium, high, on, default
token_fileLM Studio API token file, inside ~/.config/gi-ai/, mode 0600, reached without links: no symbolic link on the way and no hard link to the file
